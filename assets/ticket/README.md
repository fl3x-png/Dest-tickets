# Материалы фирменного билета

Фото спикера и десять флагов извлечены без генеративной обработки из референса, предоставленного пользователем 16.11.2026. Фотография не ретушировалась. Разрешение фото ограничено исходным скриншотом (321×361).

Все надписи в PDF рисуются отдельно, а не накладываются на старые надписи. Координаты соответствуют композиции референса 1264×669. ФИО, номер, дата, время, спикер, площадка, город и адрес подставляются из данных. Длинные ФИО переносятся максимум на три строки.

Используются системные Arial (Windows) или DejaVu Sans (Linux). Для полного совпадения начертаний необходимы оригинальные шрифты/исходный макет. Информация об опыте спикера сохранена из референса и относится к Роману Лушакову.
